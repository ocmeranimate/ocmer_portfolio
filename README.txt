# Animator / Digital Artist Portfolio

## Files
- `index.html` — page structure and content
- `style.css` — complete responsive styling
- `script.js` — mobile menu, scroll reveal, cursor glow, and project modals
- `resume.pdf` — add your actual resume here

## How to customize
1. Replace the placeholder hero artwork with your own image.
2. Replace the four project placeholders with your animation stills, character art, storyboards, and illustrations.
3. Change `your.email@example.com` to your real professional email.
4. Replace the `#` social links with your actual Instagram, ArtStation, LinkedIn, etc.
5. Put your resume in this folder and name it `resume.pdf`.
6. Open `index.html` in a browser.

For real project images, replace a placeholder `<div>` with:
`<img src="assets/your-image.jpg" alt="Description">`

For a video, you can use:
`<video controls poster="assets/poster.jpg"><source src="assets/animation.mp4" type="video/mp4"></video>`
